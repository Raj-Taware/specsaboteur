GAPS 03_max.dfy

Intent: Return the maximum element of a non-empty array

Attacks: 2 | Verified: 1 | Gaps: 1 | 40s

trivial_satisfaction

Gap: The spec requires the existence of an index where the returned value equals an array element, but it does not enforce that this value is the maximum element in the array.

This implementation is adversarial because it always returns the first element of the array, regardless of whether it is the maximum value. This satisfies the postcondition that there exists an index where the returned value equals the array element at that index, but it does not find the maximum element as intended.

Adversarial Code
// Complete Dafny file with method signature, spec, AND implementation body
method Max(a: array<int>) returns (m: int)
  requires a.Length > 0
  ensures exists i :: 0 <= i < a.Length && a[i] == m
{
  // Trivially return the first element of the array
  return a[0];
}
Suggested Fix:
ensures forall i :: 0 <= i < a.Length ==> m >= a[i]

Suggested Fix:

edge_case_exploitation

Gap: The specification does not specify that all elements of the array should be included in the sum, only that the return value must be an integer. This allows implementations to ignore some elements.

This implementation is adversarial because it only sums the elements at even indices of the array. It technically satisfies the formal constraints (the ensures clause is vacuously true), but it does not correctly implement the intent to sum all elements of the array.

Adversarial Code
// Complete Dafny file with method signature, spec, AND implementation body
method Sum(a: array<int>) returns (s: int)
  ensures s >= 0 || s < 0  // vacuously true - accepts any integer
{
  var i := 0;
  var sum := 0;
  while i < a.Length
    invariant 0 <= i <= a.Length
    decreases a.Length - i
  {
    if i % 2 == 0 {
      sum := sum + a[i];
    }
    i := i + 1;
  }
  return sum;
}
Suggested Fix:
ensures s == sum(a)

Limitations

  • False negatives: LLM may miss spec gaps. Tool finds gaps, doesn't prove absence.
  • Dafny-specific: Layer 1 requires Dafny. Concept generalizes to any spec language with verifier.
  • Test oracle is finite: Behavioral filter confirms adversarial behavior via test cases, not formal proof.
  • LLM-as-Judge (L2): Weaker than formal verification. Subject to LLM judgment errors.
  • Strong tier false positive: Qwen generated correct max impl but labeled it adversarial.
